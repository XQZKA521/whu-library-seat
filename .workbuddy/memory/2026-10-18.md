### 实机一直转圈根因（21:15）

- 日志显示 `onPageStarted/onPageFinished` 从未触发 → WebView 根本没加载。
- 原因：`DisposableEffect(webView)` 以 `webView` 状态为 key，`webView` 从 null 变成实例时旧 effect 的 `onDispose` 读取到**新值**，把刚创建的 WebView 立刻 `destroy()`，所有加载/回调静默失效。

### 登录保持实现（23:10）

- 新版系统无开源方案（网上项目均为旧版 rest/v2）。逆向官方页面：`CASLOGIN=2`，SSO 服务 `https://seat.lib.whu.edu.cn/rem/static/sso/login` → 武大统一身份认证 `cas.whu.edu.cn/authserver`（TGC 记住登录）→ 回跳带 `?token=票据` → `POST /jsq/static/public/auth/cas/{ticket}` 换新 token，全程可静默。

### TTL 实验结论（23:40）

- 决定性数据：token 签发后每 5 分钟活跃一次，**+30min 仍然 20003 过期** → token 是签发起固定 ~30 分钟有效期，活跃不续期，心跳方案无效。
- 登录保持唯一正路 = 统一认证 SSO 静默续期（CAS TGC Cookie 生命周期内，每次 token 过期自动换新）。图书馆认证登录无 CAS Cookie，静默续期会失败并回退到"请重新登录"。
- WHU CAS TGC 生命周期未测（用户可在 cas.whu.edu.cn 登录页勾选记住登录延长）。
