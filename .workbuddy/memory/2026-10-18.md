### 实机一直转圈根因（21:15）

- 日志显示 `onPageStarted/onPageFinished` 从未触发 → WebView 根本没加载。
- 原因：`DisposableEffect(webView)` 以 `webView` 状态为 key，`webView` 从 null 变成实例时旧 effect 的 `onDispose` 读取到**新值**，把刚创建的 WebView 立刻 `destroy()`，所有加载/回调静默失效。
- 修复：改用 `remember { arrayOfNulls<WebView>(1) }` 持有实例，`DisposableEffect(Unit)` 只在弹窗销毁时 destroy；factory 里加“WebView 创建”日志便于确认。
- 教训：DisposableEffect 的 key 是可变状态时，onDispose 里不要读该状态。

### JS↔Native 通道失效根因（21:35）

### "闪一下就关闭"根因（21:43）

- 滑块组件在实机上已完全正常（TAC init ok、gen 200、ready）。
- 根因：`JSONObject.optString("token","")` 在值为 JSON null 时返回字符串 **"null"**（长度 4），App 误判为"拿到 capToken"，调用 onToken → 弹窗关闭 → 预约用 capToken="null" 提交必然失败；同时 err 也被读成 "null" 显示 JS 报告。快速预约的多个候选座位又各触发一次，于是反复闪。
- 修复：readState 里用 `obj.isNull(key)` 判断后再取值，null 一律返回 null。
